# Python + DSA + Machine Learning Roadmap

A practical, phase-wise roadmap to learn Python, Data Structures & Algorithms, and Machine Learning together.

---

## Phase 1: Python Basics (2–3 weeks)
- Syntax, variables, data types, loops, conditionals
- Functions, OOP basics (classes, objects)
- File handling, exception handling
- **Practice:** HackerRank / LeetCode easy Python problems

---

## Phase 2: DSA Foundations (4–6 weeks)
- Arrays, strings, linked lists
- Stacks, queues, hashmaps/dictionaries
- Recursion, sorting algorithms
- Trees, graphs (basic traversal — BFS/DFS)
- Time/space complexity (Big O)
- **Practice:** 50–100 problems on LeetCode (easy–medium)

---

## Phase 3: Python for Data Science (2–3 weeks)
- NumPy — arrays, broadcasting, vectorization
- Pandas — dataframes, cleaning, groupby
- Matplotlib/Seaborn — visualization
- **Practice:** Kaggle datasets, EDA projects

---

## Phase 4: Math for ML (parallel, 2–3 weeks)
- Linear algebra (vectors, matrices)
- Probability & statistics
- Calculus basics (gradients, derivatives)

---

## Phase 5: Core ML (4–6 weeks)
- Scikit-learn: regression, classification, clustering
- Model evaluation (train/test split, cross-validation, metrics)
- Feature engineering
- **Practice:** 3–4 end-to-end projects

---

## Phase 6: Deep Learning (4–6 weeks)
- Neural network basics
- PyTorch or TensorFlow
- CNNs, RNNs basics
- **Practice:** image classification, text classification project

---

## Phase 7: LLMs / Advanced (ongoing)
- Transformers, Hugging Face, fine-tuning basics

---

## Suggested Timeline
| Phase | Topic | Duration |
|-------|-------|----------|
| 1 | Python Basics | 2–3 weeks |
| 2 | DSA Foundations | 4–6 weeks |
| 3 | Python for Data Science | 2–3 weeks |
| 4 | Math for ML | 2–3 weeks (parallel) |
| 5 | Core ML | 4–6 weeks |
| 6 | Deep Learning | 4–6 weeks |
| 7 | LLMs / Advanced | Ongoing |
